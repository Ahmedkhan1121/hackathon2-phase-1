# Quickstart: In-Memory Todo Python Console App

## Getting Started

### Prerequisites
- Python 3.8 or higher installed on your system

### Running the Application
1. Navigate to the project root directory
2. Run the application with: `python src/main.py`
3. The main menu will be displayed with available options

### Using the Application
1. **Add Task**: Select option to add a new task by entering title and description
2. **View Tasks**: See all tasks with their ID, title, description, and status
3. **Update Task**: Modify existing task title/description using its ID
4. **Delete Task**: Remove a task by its ID
5. **Mark Complete/Incomplete**: Toggle task completion status by ID
6. **Exit**: Quit the application

### Navigation
- Follow the on-screen menu prompts
- Enter the number corresponding to your desired action
- For operations requiring task ID, enter the numeric ID when prompted
- Enter '0' or 'exit' to return to main menu or quit application

### Error Handling
- Invalid inputs will display helpful error messages
- The application will not crash on invalid input
- You'll be prompted to try again when input is invalid
